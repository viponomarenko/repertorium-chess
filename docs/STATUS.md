# Стан реалізації (звіт виконавця)

_Оновлено: 06.10.2026 · версія 1.0.1 (збірка 5) + виправлення після аудиту 05.10_

## Підсумок

Реалізовано всі етапи M0–M9 у вигляді робочого застосунку. Перевірено:
- **90 автотестів** проходять (`flutter test`), `flutter analyze` — без зауважень;
- **iOS-симулятор** (iPhone 17, iOS 27): онбординг, встановлення стартового репертуару, повний цикл «Вивчення» (демонстрація → без підказок), помилковий хід (фігура повертається, ✗, підказка), імпорт PGN, перегляд партії з варіантами/NAG/стрілками, Stockfish (MultiPV), дерево, статистика, налаштування;
- **Android-емулятор** (Pixel 10 Pro): запуск, «Поділитися» PGN-текстом у Tabiya, майстер імпорту в репертуар.

Не перевірено вживу (потребує облікових даних користувача або публікації): вхід у Lichess OAuth і все, що від нього залежить (приватні студії, explorer, ваги, експорт у студію), завантаження партій з Chess.com на реальному акаунті, CI на GitHub (немає віддаленого репозиторію), «Відкрити в» з файлових менеджерів на фізичних пристроях. Клієнти Lichess/Chess.com покриті тестами з підмінним HTTP.

## Відхилення від ТЗ (детально — DECISIONS.md)

1. **iOS 15+** замість 13+ — мінімум Flutter 3.47 (D-001).
2. **Партії зберігаються як PGN-текст**, дерево ходів будується в пам'яті (D-004).
3. **Opening Explorer потребує входу в Lichess** — вимога API з березня 2026 (D-011).
4. **Chess.com**: місячний JSON замість `/pgn` (містить той самий PGN + метадані) (D-014).
5. **«Поділитися» текстом на iOS** — без Share Extension у v1; файли відкриваються, текст вставляється з буфера (D-019).
6. **Малювання стрілок** — режим малювання одним пальцем; двопальцеве малювання chessground — внутрішній API (D-016).
7. **Повторення**: лінія завершується, коли попереду немає прострочених позицій (D-007).

## Відкриті питання до замовника (ТЗ 12)

1. Bundle id (`app.tabiya`), контактний email для User-Agent Chess.com і сторів — зараз плейсхолдери в `lib/core/constants.dart`.
2. Адреса публічного репозиторію (зараз `github.com/tabiya-app/tabiya`) — потрібна для User-Agent Lichess, екрана «Про застосунок» і CI.
3. Планшети: зроблено адаптивний макет (дошка й панель поруч в альбомній орієнтації), окремого макета немає.
4. Зміст стартових репертуарів: інфраструктура готова, є 2 демо; справжній контент — від замовника.
5. Дизайн: запропоновано зелену палітру й іконку з конем cburnett; можна замінити.
6. **Ліцензії ресурсів chessground** — перед публікацією рекомендую форк пакета без наборів фігур з NC-ліцензіями (D-015).
